# 更新日志：

### 新增

- **CSF 音效保留**：写回显示名时保留 `WRTS / STRW` 值块与 wave 文件名，不再清空语音数据。
- **保存全部支持新增 / 克隆单位**：会写入目标 INI，并联动注册表、CSF 与 Art；克隆 Art 只写一次，不产生重复节。
- **按标签跟踪未保存状态**：保存后切回该节不再误报“未保存”；关闭程序、打开其他工程、切换配置档前会检查所有标签草稿。
- **嵌套 `#include` 路径**：相对路径优先按当前文件所在目录解析，其次工程根目录；子目录中的二级 include 可正常加载。
- **回归测试**：新增 18 项自动化测试（核心逻辑 + 离屏 UI），覆盖本次修复的关键路径。

### 修复

- 编辑器写入 CSF 中文名时，整个 CSF 的语音（wave）数据被清空。
- 工坊高级模式部署到工程 ini 后，“瘦身”会把与 rules 相同的节整节删除，导致目标文件被清空。
- 编辑器「部署到 hotfix」在 `hotfix.ini` 已存在但缺少当前节时失败（现按新增追加）。
- 「另存为」到已存在但缺少当前节的文件失败。
- 拆分工程全量保存时，会删掉被后加载文件覆盖的旧键；仅打开并保存也会改动文件。
- 删除某个键时只清理生效来源，旧副本会在下次重载后“复活”。
- 「保存全部」无法保存新增 / 克隆单位，失败后仍清掉脏标记，并会逐个节弹确认框。
- 保存成功后切回该节仍显示“未保存”；关闭窗口只检查当前标签，其他标签的草稿会丢失。
- 「丢弃修改」后草稿仍留在内存，可能被之后的「保存全部」再次写回。
- 调试窗口「回写工程」绕过确认与多文件拆分，把整节直接写进单一文件。
- 删除节 / 从注册表移除条目会写回 UTF-8 BOM；备份失败时仍继续删除。
- 节头带行尾注释（如 `[E1] ; comment`）时，保存会出现两个 `[E1]` 节头。
- 保存时在 `[Section]` 与第一个键之间插入多余空行。
- 显示名缓存指纹未包含 `#include` 文件，外部修改拆分文件后缓存不会失效。
- `+=ID` 注册查重区分大小写，可能重复注册同一单位。
- 启动器未检查 `CreateToolhelp32Snapshot` 失败，可能继续对无效句柄操作。

### 优化

- 「保存全部」只处理有未保存修改的标签，不再重写所有已打开节，也不再逐节确认。
- 高级模式部署不再自动瘦身（hotfix 瘦身仅限安全模式的 `hotfix.ini`），以数据安全优先。
- 发布工作流移除构建期从外部地址下载并覆盖 `app.py` 的步骤；`_prefer_tools_dir` 修复直接入库，删除临时补丁脚本。
- 删除节 / 注册表清理统一使用无 BOM 编码，并清理无意义死代码。
