# INI 工程编辑器 (Editor)

AutoReloader **附带工具**：工程级 INI 编辑（对象树、增删改、保存回源文件、单单位调试/hotfix）。

## 迁入计划

源码目前在独立仓库 [mo_ini_editor](https://github.com/jiu-zui-90817/mo_ini_editor)。

稳定后将整目录迁入此处，并逐步改为使用仓库根目录的 `shared/`。

## 定位

| | 战术工坊 | 本编辑器 |
|--|----------|----------|
| 场景 | 局内快调参数 | 改工程结构与全文 |
| 写入 | 主要 hotfix | 源 ini + 可选 hotfix |
