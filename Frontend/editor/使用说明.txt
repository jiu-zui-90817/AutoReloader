  INI 工程编辑器 — 使用说明
  （AutoReloader 工具链附带）
════════════════════════════════════════

【这是什么】
  面向红警2 / 尤里的复仇 / 心灵终结等 MOD 的 INI 工程浏览与编辑工具。
  支持工程目录、Ares #include、CSF 中文名、按源文件保存与自动备份。
  热重载由 AutoReloader.dll + 启动器完成；本程序可把当前单位部署到 hotfix.ini。

【推荐流程】
  1. 用配套启动器（管理员）启动游戏。
  2. 本程序打开游戏或 MOD 根目录。
  3. 在对象树选择单位 / 武器等，在中间修改代码。
  4. 「保存当前」写回来源文件（会备份）；或「部署到 hotfix」只影响热重载。
  5. 游戏内按热键或 AutoMonitor 触发重载。

【文件菜单】
  · 打开游戏文件夹 / 打开单文件
  · 保存当前 / 保存全部
  · 另存为：只导出当前这一节到新文件（不改原工程）

【工具 / 热重载】
  · 设置 hotfix 路径（默认 hotfix.ini）
  · 部署当前单位到 hotfix（不改 rules 源文件）
  · 部署并保存：先保存工程再部署

【注意】
  · 保存为 UTF-8（无 BOM），以兼容引擎。
  · 合并视图下同名节（如 Special）请结合分类/来源区分。
  · 另存为不是「另存整个工程」，只保存当前编辑的 section。

【与战术工坊的分工】
  · 编辑器：改结构、全文、批量与工程维护
  · 工坊：快调常用数值并部署 hotfix

版本与发布以 AutoReloader 仓库 Release 为准。

【搜索与校验】
  · 编辑 → 全工程搜索（Ctrl+Shift+F）：按节名/键/值搜索；支持 Primary=M60
  · 「查找引用」：查谁引用了某个 ID
  · 双击结果：打开对应节并定位到键
  · 编辑 → 校验当前节 / 校验整个工程
  · 保存当前：若存在 error 级问题会弹出校验结果，可取消或仍然保存

【MIX 只读浏览】
  · 文件 →「打开 MIX 文件（只读）…」：列出条目、搜索、预览、提取
  · 只支持未加密 MIX；加密 MIX 会提示先用 XCC Mixer 解包
  · 不写回 MIX；提取文件在缓存目录，编辑不会影响原包

【保存保护（致命错误拦截）】
  · 目标文件里同一个 [Section] 出现多次：拒绝保存，并提示重复行号
  · 新内容为空/只有注释，而原 Art 节有 Image/Foundation 等键：拒绝保存
  · 目标文件是 artmo/art*.ini，但内容只有 rules 字段：拒绝保存
  · 目标文件是 rulesmo/rules*.ini，但内容只有 Art 字段：拒绝保存
  · 这些检查在写盘前执行，失败不会覆盖原文件

【保存与自动校验】
  · 保存当前：若开启自动校验，只检查当前节；有 error 时可取消或仍保存
  · 保存全部：若开启自动校验，检查整个工程
  · 首选项 →「保存时自动校验」可关闭；关闭后仍可用「编辑」菜单手动校验

【校验覆盖（Ares 基线，摘要）】
  · 前置：General Prerequisite* 组名、GenericPrerequisites 别名、单位/建筑 ID、Prerequisite.ListN
  · 武器/弹头/抛射体：Primary、DeathWeapon、Warhead、Projectile 等
  · 超武 / 动画 / 粒子 / AttachEffect.Types：引用存在性（动画类多为 warning）
  · Owner 空、TechLevel 格式与范围；同名节多源为 info
  · 未知扩展键默认不报，避免误杀

【单位转换 / 已有单位刷新】
  · 工具 →「生成单位转换指令（Convert）…」：当前单位作为源类型
  · 写入 hotfix 的 [AutoReloader]：Convert=源>目标
  · 可同时选择写入反向转换；两条一起用，已有单位会重新读取配置
  · 实测编组和当前移动/攻击指令会保留
  · 目标必须同类别（Infantry / Unit / Aircraft）且同水域/陆地，且类型已存在
  · 目标下拉会自动过滤：海军只能选海军，陆军只能选陆军
  · 写入时会替换源类型的旧 Convert；若仍有 X>源 的旧映射会提示链式风险
